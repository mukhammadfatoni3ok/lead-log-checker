# Portfolio Note — Lead Log Checker

Lead Log Checker adalah project automation sederhana yang saya buat untuk melatih dasar-dasar scripting, Git, GitHub, dan dokumentasi project.

## Kenapa Saya Membuat Project Ini

Saya membuat project ini untuk memahami bagaimana automation sederhana dapat membantu proses pengecekan data dan log aplikasi.

## Apa yang Dilakukan Project Ini

Project ini membaca file data lead dan application log, kemudian menampilkan informasi penting di terminal dan membuat report harian secara otomatis.

## Skill yang Dipraktikkan

- Bash scripting
- Penggunaan terminal
- Membaca file
- Pemeriksaan log
- Git workflow
- Pengelolaan repository GitHub
- Dokumentasi teknis

## Pengembangan Berikutnya

Project ini dapat dikembangkan menjadi:

- Python automation script
- Scheduled daily report
- Email notification
- Telegram notification
- Dashboard sederhana
- Statistik lead
